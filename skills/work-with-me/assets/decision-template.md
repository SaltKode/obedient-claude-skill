# Decision needed

Use only for a material choice that cannot be settled inside the current authorization.

**Decision:** Name the exact change.

**Why it is needed:** Describe the verified gap or blocking evidence.

**Recommended option:** State what would change and the expected result.

**Existing-stack alternative:** Explain the viable smaller option, or why none meets the requirement.

**Consequences:** Include relevant cost, dependency, operational burden, data movement, compatibility, or reversibility.

**Ready now:** State the investigation, design, or implementation already completed within scope.

**Approval requested:** Ask for one specific action and target. Reuse existing authorization when it already covers them.
